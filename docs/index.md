## 📐 Battery Capacity Calculations

- **Watt-Hour Formula**: $\text{Capacity (Wh)} = \text{Voltage (V)} \times \text{Amp-Hours (Ah)}$
- **Runtime Estimation**: $\text{Hours} = \frac{\text{Capacity (Wh)} \times 0.85}{\text{Load (Watts)}}$
